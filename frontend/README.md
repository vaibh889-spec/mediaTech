# MediaFetch Frontend

Next.js 16 frontend for MediaFetch — a modern media downloader.

## Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- framer-motion
- lucide-react

## Setup

```bash
npm install
cp .env.example .env.local
# Edit .env.local with your backend URL
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
